Pour activer les paiements :
1. Créer un produit 100 ml à 5,99 € dans Stripe.
2. Créer un Payment Link.
3. Remplacer #STRIPE_PAYMENT_LINK# dans index.html par le lien.
4. Pour plusieurs quantités, créer la logique de paiement adaptée ou utiliser un checkout Stripe compatible panier.

Avant vente : compléter les informations légales, livraison, INCI, précautions et éléments de conformité cosmétique.
